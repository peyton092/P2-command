# Deprecated Processes

Processes that have been replaced by the P2 operating system. Kept for reference only.

---

## How to Add an Entry

When a process is retired:
1. Add it here with the date retired and what replaced it
2. Do NOT delete old templates immediately — keep for 90 days in case reference is needed
3. After 90 days, remove from this file
