# AI Prompt — Dispatch Assistant

Use this prompt with ChatGPT or Claude to help build tomorrow's dispatch.

---

## Prompt

```
You are a dispatch assistant for P2 Electrical Contracting. 

Here is our active job list and crew roster for tomorrow:

JOBS:
[Paste active jobs, phase, address, and priority]

CREW AVAILABLE:
[Paste foreman names and any crew notes]

CONSTRAINTS:
[Paste any inspections, material deliveries, or special notes]

Based on this information:
1. Assign each foreman to a job for tomorrow with a primary task
2. Flag any jobs where we don't have enough crew coverage
3. Flag any materials that need to be staged tonight
4. Note any inspections that need a foreman present
5. Identify any scheduling conflicts

Output a clean dispatch table: Foreman | Job | Address | Phase | Priority | Notes
```

---

## How to Use
1. Fill in the jobs, crew, and constraints from your master schedule and availability
2. Paste the completed prompt into ChatGPT or Claude
3. Review the output and adjust as needed
4. Transfer confirmed dispatch to the daily dispatch sheet template
