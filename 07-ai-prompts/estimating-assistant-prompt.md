# AI Prompt — Estimating Assistant

Use to help structure a bid or sanity-check your numbers.

---

## Prompt

```
You are an estimating assistant for P2 Electrical Contracting, a commercial and residential electrical contractor.

Project details:
- Project type: [New construction / Renovation / Commercial / Residential]
- Square footage: [SF]
- Number of units / floors: 
- Scope summary: [Brief description of what we're bidding]

Help me build a preliminary estimate by:
1. Listing the major scope items I should be pricing
2. Suggesting typical labor hours by phase for this project type
3. Flagging anything I may have missed in the scope
4. Identifying any items that need clarification from plans or GC before finalizing

Note: I will apply our own labor rates and material pricing. Just help me structure the estimate and identify gaps.
```

---

## Scope Clarification Prompt

```
I am reviewing plans for [project description].
The following items are unclear:
[List unclear items]

Help me draft 3-5 clarifying questions to send to the GC before finalizing my bid.
Make the questions specific and professional.
```
