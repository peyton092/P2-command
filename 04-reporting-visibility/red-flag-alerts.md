# Red Flag Alerts

These conditions trigger immediate escalation. No waiting for the next scheduled review.

---

## Field Red Flags — Notify PM within 1 Hour

| Flag | Description |
|------|-------------|
| Inspection failed | Any inspection failure — document and re-schedule same day |
| Safety incident | Any incident or near-miss — stop work, document, notify Owner |
| GC access denied | Crew shows up and can't get on site |
| Major material shortage | Work cannot continue — identify gap and ETA |
| Crew injury | Any injury — emergency services first, then Owner immediately |
| Discovered damage | Found pre-existing or site-caused damage not in our scope |

---

## Financial Red Flags — Notify Owner within 24 Hours

| Flag | Description |
|------|-------------|
| Job margin below [X]% | Pull job cost report and brief Owner |
| AR over 60 days | Any invoice unpaid past 60 days — phone call required |
| Unapproved CO work performed | Extra work done without written approval — stop and document |
| GC threatening back-charge | Document everything, escalate to Owner and legal if needed |
| Cash below [X] days of runway | Immediate cash flow review |

---

## Schedule Red Flags — Notify Owner within 24 Hours

| Flag | Description |
|------|-------------|
| Job 6+ days behind | Requires Owner visibility and recovery plan |
| Multiple jobs stalled simultaneously | Resource crisis — Owner decides crew redeployment |
| GC pushing schedule 2+ weeks | Contract review, document impact, consider delay claim |

---

## People Red Flags — Notify Owner Same Day

| Flag | Description |
|------|-------------|
| Foreman no-show with no communication | Immediate contact attempt, reassign crew if no response by 7:30 AM |
| Crew altercation on site | Stop work, separate parties, Owner decides next steps |
| Foreman scorecard below 13 | Termination review meeting within 48 hours |
| Key person resignation | Owner handles directly |
