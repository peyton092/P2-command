# 30 / 60 / 90 Day Takeover Plan

**Acquired Company:** | **Close Date:**
**P2 Integration Lead:**

---

## Days 1–30: Stabilize

**Goal:** Nothing breaks. Money keeps moving. People stay.

### Operations
- [ ] All active jobs mapped into P2 master schedule
- [ ] P2 daily dispatch system adopted by all foremen
- [ ] Daily foreman reports started (use P2 template)
- [ ] CompanyCam set up for all active jobs
- [ ] All billing current — no gaps from transition

### Finance
- [ ] All AR transferred and collected under P2
- [ ] AP reviewed — which vendors to keep, consolidate, or cut
- [ ] Bank accounts fully under P2 control
- [ ] Job profitability tracker started for all active jobs
- [ ] Payroll running smoothly under P2 system

### People
- [ ] Every key employee has a 1:1 with P2 leadership
- [ ] Employment agreements signed
- [ ] Compensation review completed — no surprises pending
- [ ] Top performers identified
- [ ] Under-performers identified (no action yet — observe)

**30-Day Review:** Owner + PM — what is working, what is broken, what is the risk?

---

## Days 31–60: Integrate

**Goal:** Replace their chaos with P2 systems.

### Operations
- [ ] Scheduling fully migrated to P2 master schedule
- [ ] 3-week lookahead running for all jobs
- [ ] Stalled jobs identified and recovery plans active
- [ ] Inspection pass rate tracked

### Finance
- [ ] All invoicing running through P2 billing system
- [ ] Change order process adopted
- [ ] First monthly job profitability review completed
- [ ] First cash report issued for acquired entity

### People
- [ ] Foreman scorecards started
- [ ] First scorecard reviews held
- [ ] Any performance issues now on formal improvement plan
- [ ] Organizational chart finalized

### Systems
- [ ] Old software phased out (or timeline set)
- [ ] P2 reporting cadence fully running

**60-Day Review:** Financial performance vs. acquisition projections. On track?

---

## Days 61–90: Optimize

**Goal:** Run it like a P2 division. No legacy chaos remaining.

### Operations
- [ ] All jobs in P2 system with clean history
- [ ] Schedule adherence rate tracked and improving
- [ ] First inspection pass rate vs. P2 baseline measured

### Finance
- [ ] First full month of P2-integrated P&L available
- [ ] Margin by job type benchmarked vs. P2 standard
- [ ] Any underperforming jobs identified and addressed

### People
- [ ] First full foreman scorecard cycle complete
- [ ] Any terminations executed (with documentation)
- [ ] Any promotions or key hires made
- [ ] Culture alignment assessed

### Growth
- [ ] GC relationships reviewed — any new opportunities from acquisition?
- [ ] Geographic expansion opportunities identified
- [ ] Integration learnings documented for next acquisition

**90-Day Review:** Full acquisition performance review with Owner. Declare integration complete or extend timeline.
