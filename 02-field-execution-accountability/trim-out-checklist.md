# Trim-Out Checklist

**Job:** | **Foreman:** | **Date:**

Complete before calling for trim inspection.

---

## Devices
- [ ] All outlets installed and tested
- [ ] All switches installed and functional
- [ ] GFCI outlets installed at all required locations (bathrooms, kitchen, exterior, garage, unfinished basement)
- [ ] AFCI breakers installed where required
- [ ] All covers installed — no open boxes
- [ ] Tamper-resistant receptacles where required (residential)

## Fixtures
- [ ] All lighting fixtures installed per plan
- [ ] Recessed cans — trims installed
- [ ] Fan boxes rated for fan weight where fans installed
- [ ] All fixtures functional and aimed/adjusted

## Panel
- [ ] All breakers installed and landed
- [ ] Panel directory complete and accurate
- [ ] Panel cover installed
- [ ] Main breaker labeled
- [ ] No open knockouts in panel

## Testing
- [ ] Outlet tester run on every receptacle
- [ ] All GFCI locations test/reset functional
- [ ] All circuits labeled and tested
- [ ] Smoke detectors installed and interconnected (if in scope)
- [ ] CO detectors installed (if in scope)

## Documentation
- [ ] CompanyCam trim photos uploaded
- [ ] Panel directory photo in CompanyCam
- [ ] Any deviations noted
