# Rough-In Checklist

**Job:** | **Foreman:** | **Date:**

Complete this checklist before calling for rough-in inspection.

---

## Panel / Service
- [ ] Panel location confirmed per plans
- [ ] Panel rough set and secured
- [ ] Service entrance conduit run (if applicable)
- [ ] Grounding electrode system started
- [ ] Panel size matches contract / permit

## Wiring Runs
- [ ] All circuits run per plan
- [ ] Wire gauge correct per circuit type
- [ ] All wire labeled at panel end
- [ ] No wire running through fire-rated assemblies without proper firestop
- [ ] MC/NM secured every 4.5 ft and within 12" of boxes

## Boxes
- [ ] All outlet, switch, and fixture boxes installed
- [ ] Box fill calculated — not overfilled
- [ ] Boxes at correct height (per spec or standard)
- [ ] All boxes accessible (none buried in wall)
- [ ] Weatherproof boxes where required (exterior, wet locations)

## Underground / Slab (if applicable)
- [ ] Conduit depth meets code (24" for 120V, 18" with GFCI, 6" under slab)
- [ ] Sleeves at slab penetrations
- [ ] Photos taken before backfill/pour

## Safety
- [ ] All energized conductors protected
- [ ] Arc flash and shock hazard labels where required
- [ ] No open splices

## Documentation
- [ ] Permit posted on site
- [ ] Plans on site and match what was installed
- [ ] CompanyCam rough-in photos uploaded
- [ ] Any deviations from plan documented and approved
